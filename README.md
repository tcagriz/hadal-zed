# Hadal for Zed

A deep-sea dark theme for [Zed](https://zed.dev), part of the Hadal theme suite.
Colors are based on the VS Code Abyss theme (see `LICENSE` for attribution).

## Install

From the Extensions panel, search for **Hadal**, then pick it in `settings.json`:

```json
"theme": {
  "mode": "dark",
  "light": "One Light",
  "dark": "Hadal"
}
```

### Manually

Copy `themes/hadal.json` to `~/.config/zed/themes/hadal.json`.

## Development

`themes/hadal.json` is generated from the suite's `palette.json`; do not edit it by hand.
